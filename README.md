# Express Boilerplate

An Express Boilerplate with Javascript ES6 style and Sequelize

## Installation

Clone this express-boilerplate with git

```bash
  git clone https://github.com/farhannjb/express-boilerplate
  cd express-boilerplate
  yarn install
```

## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`TOKEN_SECRET`

`MYSQL_HOST`

`MYSQL_PORT`

`MYSQL_USER`

`MYSQL_PASS`

`MYSQL_DB`

## Features

- `nodemon`
- `jsonwebtoken`
- Logger with `morgan` and `chalk`
- ORM with `sequelize`
- Supported DB:
  - MySQL
